Guide 1 of 2 — Installation

Installing RADIX Phone

A single installer sets up the RADIX Phone Windows Service, its client files, and the standalone Configuration Editor — walking through SIP transport, ring, and codec settings before the first file is even copied.

RADIX Phone 4.19.1.03.exe

Overview

What the installer sets up

One executable, three moving parts.

Running RADIX Phone 4.19.1.03.exe installs three things together: the RADIXPhone Windows Service (the actual SIP client, running under the service account), its supporting client files under {app}\Client, and the standalone Configuration Editor under {app}\ConfigEditor for editing settings after the fact. Two Start Menu shortcuts are created — one for each.

Uniquely, this installer's wizard doesn't stop at picking a folder — it walks through the same five configuration steps as the standalone Configuration Editor (see the companion guide) before installing, so properties.json is written correctly on first boot instead of shipping with placeholder defaults.

Before you run it

Running the installer

One requirement, no way around it.

Always runs elevated

Setup always requests administrator privileges — there is no "install for me only" option. It needs admin rights to create the Windows Service, write to Program Files, and install the prerequisites below. Approve the UAC prompt to continue; declining exits Setup immediately.

Step 1

Welcome & required components

Setup opens with a standard Welcome screen, then discloses exactly what it's about to install.

After the Welcome page, Setup shows a read-only disclosure of every prerequisite it depends on — not optional tasks you can uncheck, just an honest list of what's required and whether it's already on the machine:

When something's missing, Setup installs it silently later in the process — see Installing.

Steps 2–3

Destination & additional tasks

Standard Inno Setup pages — skipped entirely on an upgrade.

Next comes the standard Select Destination Location page (defaults to Program Files\VIS\RADIX Phone). If a previous install is detected at that path, Setup skips straight past it and reuses the existing folder rather than asking again.

Steps 4–7

The configuration wizard

The same five steps as the standalone Configuration Editor, embedded directly in Setup.

Before a single file is copied, Setup walks through Transport, Ring & Audio, Notification Speaker (shown only if enabled), and Codec Priorities — writing the results into properties.json once installation actually runs. If a previous install's config already exists at the destination, every field is pre-populated from it instead of built-in defaults, so re-running Setup to upgrade doesn't reset your settings.

Same fields, same validation

Port ranges, ring volume, max ring time, and codec priorities are validated the same way here as in the standalone editor — see the Configuration Editor Guide for what every field means and how it's validated.

Step 8

Ready to Install & Installing

The last chance to review before anything is written.

Ready to Install summarizes the tasks selected (autostart, if checked) and gives one last Back to change anything. Clicking Install begins the real work: any missing prerequisite from the disclosure page is installed silently first, then files are copied, then the RADIXPhone service is (re)created and started.

On an upgrade, the service restarts

If RADIX Phone is already running, installing again stops it, replaces its files, recreates the Windows Service definition, and starts it again — actively serviced calls are interrupted. Plan upgrades accordingly on a production machine.

Step 9

Finish

Nothing launches automatically — you choose when.

Re-running Setup

Reinstalling & upgrading

Existing configuration is respected, not overwritten blind.

  • Existing config is preserved — if properties.json already exists, the wizard pre-populates from it and only writes back what you confirm through the same five steps; there's no separate "keep my settings" checkbox to remember.
  • ConfigEditor is always replaced cleanly — Setup deletes the entire ConfigEditor folder before recopying it, so a version change there never leaves stale files mixed in with new ones.
  • The running app is killed first — Setup force-terminates RADIXPhone.exe at the very start, before anything else happens.

Removing it

Uninstalling

Via the usual Windows path — no separate uninstaller shortcut.

Use Settings → Apps (or Control Panel's Programs and Features) and remove RADIX Phone. The RADIXPhone Windows Service is stopped and deleted as part of uninstall, before the rest of the files are removed.
